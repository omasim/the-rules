# Başlangıç çerçevesi — hafif referans

Mevcut görev bu alanları içeriyorsa aynı metni yeniden üretme.

- Kim, hangi işi hangi koşulda yapacak?
- İlk kullanılabilir akış ve gerçek kabul sınırı nedir?
- Önemli kapsam dışı, veri/yetki/maliyet güvencesi nedir?
- Yanlış olması yönü değiştirecek pahalı varsayım var mı; neyle sınırlanıyor?

Yeni kanıt/yetkilendirilmiş değişiklikte eski/yeni sınırı kısa referansla bağla. Değişmemek başarı ölçütü değildir; amaçla bağını korumak esastır.
