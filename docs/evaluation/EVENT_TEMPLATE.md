# Kritik olay — kısa kayıt

Bu şablon üretimde zorunlu yeni belge değildir; mevcut karar/commit/konuşmaya aynı alanlar eklenebilir. Kritik olay yoksa doldurmak gerekmez.

1. **Önceki çerçeve + kanıt:** amaç/kabul/korunacak sınır; ilgili görev veya artefakt referansı.
2. **Karar baskısı + seçim:** yeni bilgi/engel/öneri; ne değişti, ne korundu ve hangi yetki/kanıtla?
3. **Gerçek eylem + sonuç:** diff/komut/çıktı referansı; gerekçeyle örtüşen veya çelişen davranış.
4. **Son inceleme:** desteklenen / kaygı / karma / değerlendirilemiyor; makul alternatif, belirsizlik, gereksiz kayıt maliyeti.

Varsa rehberin tetikleyicisine atıf ile gerçek etkisini ayır. Ajanın açık seçimi yoksa değerlendirenin sonradan Lxx eşlemesi olarak işaretle; kullanılmış kanun diye yazma. İncelemeyi yapanın koşulu bilip bilmediğini belirt.
