# Contributing

Open an issue with the task, observed failure, relevant rule/source IDs, expected behavior, and concrete evidence. Include tool/version and reproduction steps for integration defects. Remove credentials, personal data and private project text.

For rule proposals explain scope, proportionality, source support, counterexamples and what observation would change the decision. Proposed wording is DRAFT; a passing tool check does not ratify a law. Preserve negative results and previous criteria when auditing experiments.

No contributor license policy exists yet. Discuss substantive code or content contributions before submitting material requiring a rights grant. Do not include third-party content without a suitable basis.
