# Security

Rules are advisory context, not a permission boundary. Use the host AI tool's actual permissions and sandbox. The installers are local file-writing tools; review them and version-control your project before use. Global accounts/settings are outside their scope.

Do not post credentials or sensitive exploit details in public issues. A private reporting contact has not been configured; use an already verified private contact with the maintainer for sensitive reports. No response-time commitment or independent security audit is claimed.
